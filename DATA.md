# Data

driftlens ships no external datasets. Everything under `testdata/` and `examples/`
was written for this project, is synthetic, and is covered by the repository's MIT license.

| Path | What | Source |
|---|---|---|
| `testdata/scenarios/*/applied.yaml`, `desired.yaml`, `config.yaml`, `crds.yaml`, `scenario.yaml` | Hand-written Kubernetes manifests and scenario scripts | Authored for this repo |
| `testdata/scenarios/*/live.yaml` | Live objects (with real `managedFields`) captured from a local kube-apiserver 1.37.0 (controller-runtime envtest) after running each scenario. UIDs, resource versions and timestamps are replaced with fixed values | Generated by `make fixtures` |
| `testdata/scenarios/*/expected.{txt,json}` | Golden reports | Generated by `make golden`, checked against live runs |
| `eval/results-seed-*.json` | Mutation-evaluation scores | Generated by `make eval [EVAL_SEED=n]` |
| `pkg/manifest/testdata/` | Small loader fixtures | Authored for this repo |
| `examples/shop/` | Demo application manifests and config | Authored for this repo |

Image names under `ghcr.io/example/...` and `registry.example/...` are placeholders and
do not exist. The Secret value in `in-sync-defaults` (`not-a-real-secret`) is a dummy.

The envtest binaries (kube-apiserver and etcd, Apache-2.0) are downloaded by
`setup-envtest` into the user's cache and are not committed.
